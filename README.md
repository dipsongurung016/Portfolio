## Featured Projects

### 1. SentinelFlow — AI-Assisted SOC Automation

[View Repository](https://github.com/dipsongurung016/SentinelFlow-SOC-Automation)

Built an automated SOC monitoring and alert-triage workflow integrating Splunk, n8n, Google Gemini and Slack.

- Implemented SPL-based Windows failed-logon detection using Event ID 4625.
- Integrated Splunk with n8n through the REST API.
- Configured scheduled monitoring, event grouping and duplicate suppression.
- Implemented AI-assisted investigation summaries and Slack notifications.
- Configured retry mechanisms and a separate error-handling workflow.
- Validated the end-to-end detection pipeline through controlled authentication-failure simulations.

**Technologies:** Splunk, SPL, n8n, Google Gemini, Slack, Docker, Windows, Kali Linux.

**Status:** Completed — validated in a controlled lab.
